# 外观面板、背景皮肤与出框

外观入口分为「主题选择」与「自定义主题」。前者管理内嵌主题、个人主题和主题插件；后者保留部件选择、2D／3D 预览与未保存草稿保护。云端目录复用插件中心的索引、缓存、安装、版本兼容与变更通知，仅接纳 `manifest.type` 包含 `theme` 的条目；同步目录不自动安装或更新插件。

「内框背景」统一编辑内容区域的底色、背景图片和明暗，不再把背景与内面板分成两个入口。「外框」编辑外围窗口。侧栏、标题栏、播放栏和卡片仍可分别设置。旧的 `background` 导航入口兼容指向内框背景，已保存主题仍可读取。

「背景皮肤」是一张部件自身使用的完整图片。例如，播放栏的中央图案铺在播放栏背景，PNG 的透明轮廓和边缘装饰可以越过播放栏矩形。图片始终位于该部件文字、按钮和焦点提示的后面，透明区域透出原来的背景。通用控件保留材质与颜色设置，不再把上传图片复制到每个按钮或输入框。

皮肤支持整体透明度、大小、水平／垂直位置，以及「拉伸填充」「完整显示」「铺满裁切」。选择内部显示时，皮肤受部件边界裁切；选择出框显示时，边缘可以越过部件及父容器，应用窗口仍是最终绘制边界。若整张 PNG 已按所需外形制作，可直接调整大小与位置；若图片按 UV 模板制作，可在高级设置中指定原图上、右、下、左的边缘比例，中央区域对应部件主体，边缘区域在主体之外展示。四边各为原图的 0–45%，大小为 20–300%，位置以部件尺寸的百分比偏移（−100–100%）。

2D 与 3D 使用相同皮肤参数。3D 中的主体背景和出框部分随所属部件平面一起移动，外框与内框背景拥有对应的独立平面；不把出框图片固定贴在预览视口上。预览与实际应用复用图层数据，不写入确认设置。取消或放弃草稿恢复原主题。

编辑器工作区仅轻微区分于应用底色，编辑器工具不继承画布中的出框装饰。图片导入期间保护应用、离开与草稿切换；导入失败或过期的结果不能覆盖其他部件、明暗模式或当前草稿。PNG 保留原始透明和半透明像素，不经过封面 JPEG 缩略图转换，不附加底色、光晕或模糊。

兼容与数据约定：

- 图层范围保持版本 1：`inner-panel` 为内框背景，`outer-panel` 为外框，`controls` 为通用控件，`navigation` 为侧栏，`material` 为标题栏，`player-bar` 为播放栏，`card` 为卡片。
- 每个明暗模式可保存独立的 `body`、`effect` 和 `skin`。`body` 保留主体背景颜色；`effect` 保留已有颜色、扩展、柔化与动态效果；`skin` 保存 `enabled`、`image`、`opacity`、`scale`、`x`、`y`、`placement`、`fit` 和四边 `frame`。皮肤透明度不改变文字或按钮透明度。
- 只接受现有本地导入接口返回的 `background://` 图片句柄，不接受远程网址、任意文件路径或脚本地址。没有显式 `skin` 的旧主题，可迁移非通用控件的旧图片字段；通用控件旧图片停止绘制，已有颜色效果继续兼容。
- 出框绘制不接收点击或键盘事件，不扩大主体点击范围。滚动、尺寸与布局变化按帧合并更新；无启用图层时不测量，隐藏页面停止刷新，动态遵循减少动画与关闭动画设置。
- 应用草稿、个人主题和结构化主题插件使用相同的 `appearanceLayers` 数据。个人主题的修改写入其档案，其他主题和全局图层不受影响。当前主题归档只打包 `profile.assets`，本地 `background://` 图片不会自动随归档复制到另一台设备。
