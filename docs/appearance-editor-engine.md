# 外观编辑器视图引擎

更新日期：2026-10-13。

## 分层

| 层         | 文件                                                                   | 责任                                                                             |

引擎不读取主题存储、歌曲、Vue 组件或插件文件。它接收节点边界、画布尺寸及浮层边界，通过 `render(camera)` 更新显示；调用方提供帧时钟，使动画可以独立测试。

预览直接挂载真实 `TitleBar`、`SideMenu`、`LocalDashboard` 和 `PlayerBar`，采用各组件的预览模式与固定本地示例歌曲。组件尺寸、字号、间距、图标和响应式规则均来自生产样式，同时镜像 App 的壳层样式作用域。源视口等于当前窗口尺寸，先按 1:1 排版，再由唯一相机整体等比缩放，禁止为单个控件另设比例。日期、专辑元信息和次要列表文字在原文字行框上覆盖圆角矩形；不删除原布局、不替换真实图标。

导航收起隐藏完整导航容器；展开恢复真实导航。显示选项、导航排序及三种播放栏形态的按钮排列使用同一外观草稿，支持预览、撤销、重做、放弃和一次显式应用。插件页面定义沿现有页面列表传入；未知配置保留。日常属性面板用实体浅深底色，默认折叠新增排列设置。

预览模式不启动首页 DSP 轮询、窗口控制、导航根观察器、播放器供方同步或扩展事件监听，也不挂载隐藏的队列和添加到歌单面板。示例歌曲显式标记为本地来源，进度显示使用静态值，避免误识别工坊 ID 为插件供方，或跟随实际音频时钟重绘。导航完整覆盖窗口，只有滚动内容按预览播放栏的真实边界预留空间。相机动画与加载阶段仅作用于场景外层。

## 扩展部件

在外观部件注册表中添加部件 ID、展示信息和预览选择器，并在业务属性面板中接入该部件的字段。测量、完整适配、命中区域和周围淡化区域由注册项生成，不需要在相机计算中增加部件判断。

`preview` 的 `focus: 'scene'` 用于背景等需要查看整窗的对象；默认策略适合完整部件。`maxScale` 可限制较小部件的最大默认放大倍率。属性数据继续使用现有草稿与主题契约。

复用到其他编辑界面时，通过 `setScene(size, nodes)` 注册不同的节点，提供对应的渲染适配器与属性面板即可。引擎测试使用了新的 `future-plugin-widget` 节点，验证它能够复用适配、缩放和复位行为。

## 操作契约

外观页面顶部只保留一条工具栏：外观选择、新建、主题选项、明暗预览和 3D/相机入口共用这一行。删除、缩放、适配、返回整窗、导航状态和层间距在所有尺寸都收进主题选项；日常调整不再重复显示画布内的标题与工具栏，仍保留可访问的名称与键盘操作。单独使用外观调整组件时沿用其自身工具栏。

新建先保护当前草稿，再从默认外观生成独立命名的外观，保存成功后激活并进入制作。保存失败不激活；激活失败保留已保存的新外观，允许重新选择。删除只针对已经保存的用户外观，先确认再处理未保存草稿；取消不释放当前制作预览。默认及其他内置外观由界面和主题库共同禁止删除，插件项目通过同一外观选择进入制作；素材、诊断和导出在按需工具中管理。删除当前外观回到默认，删除其他外观保留当前选择。

- `resize(size, panels)`：画布或面板尺寸改变后重新计算未被遮挡的区域。
- `focus(id)`：切换对象，清除上一对象的手动平移和缩放，适配完整边界。
- `zoomBy(factor, anchor)`：围绕指针或可用区域中心平滑缩放。
- `panBy(delta)`：跟随拖动平移，并保持对象至少有一部分可找回。
- `fit()`：清除手动视角，恢复完整适配。
- `setAnimated(false)`：减少动画或关闭动画时立即到达目标。
- `setActive(false)`、`dispose()`：停止帧调度；恢复时使用最新目标。

默认视角完整展示部件，整窗其他内容保留在原位置并淡化。周围的模块仍可点击，切换时移动同一个场景。手动放大可能超出画布，用户可以拖动查看各处，或使用适合部件返回。切换部件和视角不保存属性，也不清除草稿。

日常选中属性显示在画布上方的横条，详细属性按需展开。相机始终按完整画布居中和适配，不扣除右侧属性浮层的宽度，也不因其展开、收起或滚动而移动焦点。制作工作区同样使用上方横条。玻璃配色解析与运行时共用纯函数，并通过已有根属性观察器更新实际配置；背景与卡片按各自配色编辑。

插件项目复用自定义当前主题的画布、对象选择、相机、2D/3D 和上方属性横条。工坊组件以 `controlsOnly` 提供项目、素材、图层、模式、参数、源码、诊断和导出控件，不挂载第二个 iframe。预览页、宽度、状态和画布编辑收在默认折叠的预览选项里；日常草稿、主题配置和插件项目继续使用各自的存储与提交契约，不把个人设置写入插件包。已经编辑项目时，“自定义当前主题”保留该项目并聚焦属性。

`appearanceWorkshopPreview.ts` 是共享模型与诊断适配器的边界。画布只渲染最后有效的编译项目；属性中的无效草稿保留。检查等待实际页面、配色、宽度、状态、CSS、装饰层和几何提交完成；隐藏或未就绪会明确中止。图层框使用同一源坐标与等比相机，手势进入原项目撤销历史；3D 展示静态组装关系，图层拖拽在 2D 编辑。文字输入保留原生撤销，其他工坊控件支持 Ctrl/Cmd+Z 与 Shift+Z。

指针点击画布空白或背景命中区域返回整窗，属性浮层的控件操作保留当前对象。通过对象选择栏或键盘选择背景时，整窗仍显示，标题栏、导航、播放栏及首页前景降低不透明度，背景保持清晰。导航与具体选中对象的真实边界重叠时，仅将导航降到内容之后，避免遮住焦点；不改变手动展开状态，返回整窗、背景或导航时恢复原层级。

“3D 叠层展示”按背景、首页内容、导航、播放栏、标题栏的实际顺序展开，默认上下、左右均为 0°，通过层间距展示组装关系。画布左侧与底部的弧形刻度分别调整上下 -30° 至 30°、左右 -60° 至 60°，保留原生滑杆的键盘操作与焦点提示。层间距滑杆可合拢或展开。它保留真实源组件的 1:1 排版，在同一个预览文档中按需创建 inert 静态克隆，再整体投影。固定定位的三个 chrome 控件按源边界定位，防止转换包含块后错位。四角投影与命中多边形使用同一数学模型；切换部件、层间距和相机操作都不重新挂载业务组件或保存草稿。

2D 与 3D 切换使用通用 `createEditorTransition` 接口，以 400 毫秒缓动展开角度和层间距，并从当前已显示的位置反向复原。关闭 3D 时保留副本直到叠层合拢，再恢复原场景。鼠标在 3D 画布中移动时，通过 `createEditorParallax` 平滑增加上下最多 4°、左右最多 6° 的视差偏移；实际合成角度仍受上述范围约束。移出画布后平滑回正。两种动效只在运动中申请帧，停稳后停止；隐藏时取消，减少或关闭动画时直接完成切换并关闭鼠标视差。视差帧只更新两个显示变换和命中/选择轮廓，不测量或复制原组件，也不改变相机目标。

叠层展开时，背景向后、向下沉，前景相对背景向上浮起。标题栏、侧边栏与播放栏只按其真实边界参与完整适配，不用虚拟整窗平面抵消上浮；CSS 位移和命中投影使用同一装配偏移。为保持完整可见，整体适配仍可能移动整组画面，不能把每个部件的绝对屏幕坐标都强制向上。角度和层间距同时为零时保持原始 1:1 排版。

Chromium 的 3D 分层会切断跨平面的玻璃背景取样。玻璃标题栏、导航和播放栏因此按需补充同一平面内的静态背景/内容取样背板，裁剪到控件实际范围，继续使用原控件的玻璃滤镜。取样使用已准备的静态显示副本，无第二套业务组件或额外普通模糊滤镜；它展示原排版位置的材质上下文，不模拟不同展开层实时互相折射。仅在模型/样式变更时重建，角度、间距及视差帧不重新取样；关闭或隐藏时随叠层释放。

取样最多使用三个紧裁剪上下文和六个准备后的背景/内容子树副本。插件 App 装饰保留直接子节点选择器、条件、遮罩和底色叠加；三个取样上下文各可带一个小装饰副本，每份最多八层。原生窗口底色使用一次独立静态绘制层，位于 App 装饰之上、内容之下，取样副本沿用同一绘制层；不在每个玻璃上下文重复绘制整窗伪元素。

缩放和平移直接更新同一世界层的变换，不触发 Vue 组件树更新或重新测量。命中区域和淡化区域随实际显示一起移动。动画被打断时从已显示的帧继续，拖动也从当前显示位置接管，避免跳到尚未完成的目标。

2D 部件淡化区域为选中边界以外的四个不重叠平面，保留 10 像素间距，使部件边缘不被遮挡。3D 使用投影四边形的同等间距开孔。两者都在合成后的场景上覆盖一次当前预览背景色，使用 60% 不透明度，淡化过渡 180 毫秒；不单独降低普通玻璃平面的 alpha，避免切换视图改变颜色。背景选择立即清除外部淡化遮罩，只降低三个 chrome 和页面前景的透明度；页面容器、ambient、全局背景和插件装饰层保持原绘制，避免背景出现灰偏。业务场景只挂载一次；只有 3D 开启且可见时保留静态 DOM 副本，无额外模糊或大面积阴影滤镜。尺寸与节点比较使用数值字段；相同输入不重启动画或重复渲染。根样式先过滤再同步，避免反复写入并删除同一组样式。

画布与属性容器不保留装饰内框。当前对象使用明确的中性 2px 选择轮廓，结合周围淡化和导航状态；键盘焦点使用独立 3px 提示。点击部件保留原操作焦点，避免跳到无交互标题。首次打开使用临时轮廓、真实标题栏底边呼应和圆角矩形占位，再显示完成实际测量的场景；使用通用动效接口而不恢复预览内全部控件动画，详见 [控件与边缘动画接口](ui-motion.md)。

相机的 `motion(running)` 回调只在运动开始和停止时执行，适配器可以据此暂时启用 `will-change: transform`。隐藏窗口停止相机、镜像和测量任务，并停用玻璃光学观察器；恢复时采用最新草稿和目标，不补播过期动画。

3D 克隆只在源模型、样式或布局变更时重建；层间距与选择变化只更新投影、层变换和不透明度。相机帧不测量源 DOM、不克隆、不写子控件样式。关闭 3D、隐藏或卸载时释放静态副本、动效和监听器，恢复显示时按最新模型重建。

示意场景状态与样式镜像在同一帧提交。隐藏期间冻结侧边栏状态、播放栏模式和材质开关对应的渲染模型，恢复时只提交最新值，防止响应式子组件在暂停期间继续重绘。编辑界面和加载轮廓使用中性灰白色，示意窗口里的用户主题变量仍可预览。

## 指针跟随与角度调节

## 指针越界与取消

视差的有效范围是画布的实际边界，不能把越界位置夹到最大倾斜继续跟随。离开后只撤销鼠标偏移，以有限的 120 毫秒缓动返回用户设置的基础角度；反复越界不延长截止时间。基础上下/左右角度、相机倍率、当前对象和主题草稿均不由这条路径修改。指针捕获期间也检查真实坐标，不能仅依赖 `pointerleave`。

指针取消、丢失捕获、窗口失焦及暂停立即清除视差和未完成请求。手势结束先清空内部状态再释放捕获，防止随后到达的捕获事件再次取消新操作。进入浮动工具、相机刻度或滚动导致画布边界失效时，撤销旧鼠标偏移；重新回到画布才采用新位置。切换 2D/3D 仍从当前显示姿态展开或合拢。

全局滚动服务只在 token 确实变化时写 class，移出文档及窗口失焦取消已排队的指针帧。预览根观察器只忽略 `te-auto-scrollbar`、`is-scrollbar-near`、`is-scrollbar-active` 三种瞬时滚动提示，以及无差异属性写入。未知 class 与真正改变的主题 data/style 属性继续更新，不能以停止全部观察来换取性能。
