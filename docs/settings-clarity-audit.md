# 设置页可理解性审查

## PR #120 对 Pxasen 的整合（2026-10-10）

本次以 `Pxasen` 的 `45a3c966` 为目标，合并原 PR 分支并解决重叠的设置重组与外观编辑器冲突。保留目标分支已有的七分类、独立外观编辑器、音频处理与稳定搜索 ID，将分类切换和布局修复接入这些结构。

- 七个分类只显示当前面板，其他面板通过 `v-show` 保持挂载；输入、编辑草稿和折叠状态跨分类保留。关闭再打开设置仍恢复上次分类，慢速启动不会覆盖用户的新选择。
- 预留稳定滚动条空间，长短分类保持内容宽度。桌面侧栏支持方向键、Home/End 和单一 Tab 停靠点；聚焦分类时同时滚动侧栏，窄窗口使用原生分类菜单。
- 搜索先显示目标分类，再展开、测量、滚动与聚焦。沿用目标分支的稳定 ID 和兼容别名，避免版本/下载更新定位到整类；聚焦原生按钮时保留其 Tab 顺序。
- 更新偏好使用标准设置行，检查间隔的禁用原因通过 `aria-describedby` 关联到控件。下载文件名示例说明后缀由音源决定，保留原 PR 的设备档案中文说明。

本轮 Windows 验证：设置相关测试 91/91；最后修改后分类与搜索集成测试 2/2。真实组件在 760/1024/1440px、深浅色与三种材质下通过溢出与搜索弹层检查；复核宽屏播放及窄窗口系统页截图。主进程/渲染进程类型检查、修改文件 lint/format、生产构建和原有渲染资源预算通过。截图复核发现的旧前置条件提示残留已清理，并覆盖分类切换与新搜索。未验证当前云端 CI。以下各节为原 PR 的历史审查与迭代记录；其中十三分类、旧折叠实现、实机复核、测试数量和云端检查状态属于各自历史提交，不代表本次整合后的结构或验证结果。

## 视觉与交互复核

设计以 Apple HIG 的清晰层次、常用项优先、渐进展开和一致反馈为主，同时适配 Windows 桌面的窗口、原生选择框、键盘与焦点行为。保留应用已有的主题色、可选字体、柔和背景、圆角和液态玻璃选项，不引入系统字体强制覆盖，也不改变用户保存的外观偏好。

| 同级问题                                                       | 修复                                                                                            |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 左侧导航在窗口中间，内容从顶部开始，视觉主轴分离               | 导航与正文顶部对齐；窄窗口使用分类选择框                                                        |
| 点击“分类”只是滚动长页，手动滚动和异步加载可能改变当前选择     | 每次显示一个分类；分类切换保留已挂载面板、草稿与展开状态；加载完成不重新选择分类                |
| 分区模板、控件宽度、标题层级和行间距不一致                     | 保留原版标题、行与控件皮肤；修复窄窗口对齐及字段尺寸；字体随主题正文大小缩放                    |
| 高频设置被空设备档案、工坊和音频状态图抢占                     | 主题模式与颜色前移，工坊后移；设备档案、音频链路及网络开发选项默认折叠                          |
