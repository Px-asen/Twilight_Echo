# 第二阶段：多 Zone、会话接力与同步

2026-11-03，进行中。沿用第一阶段的 TLS PCM Bridge；手机／双机／DAC 实机测试继续后置。

## 验收顺序

1. 同一 Core 的多个 Zone 各自拥有队列、播放位置、DSP、持久化和隔离音频进程；一个输出故障不停止其他 Zone。原本未带 Zone 的入口仍指向原 `local` 会话。
2. 会话接力复制队列与当前位置，目标确认接管后再恢复播放；不共享可变 SQL 队列游标、不自动重试未知结果、不丢弃目标已有队列而不确认。
3. 同步组需要统一时间基准、持续的输出时钟估计、漂移修正和掉线／重缓冲策略，并测量长时间同步误差。独立并发播放或同时发送 Play 不等于同步。

当前实施第一项及其生产入口、界面和回归；接力与同步的完成状态将在取得对应实现与证据后更新，整个第二阶段尚未完成。
