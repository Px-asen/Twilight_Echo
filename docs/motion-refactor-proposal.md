# Twilight Echo 动效重构

更新：2026-11-06。主导航、页面切换、播放页展开、抽屉和拖拽已接入统一动效；本轮补齐速度连续、面板方向与跟手细节。

## 方向：立即响应，移动连贯，轻轻收住

点击直接改变目标，不用等上一段动画结束。页面用短距离位移交代方向，导航选中背景连续追踪；封面、抽屉和重排在中途换目标时继承位置与速度，先自然减速再转向。大面积文字保持稳定。实现沿用 Vue、CSS 和 Web Animations API，没有新增动画依赖。

## 维护入口

### 页面过渡：`components/MotionTransition.vue`

- 统一管理进入、退出、反向与清理，通过 `transform`、`opacity` 绘制。
- `snapshot` 将离场视图变为不可交互、`aria-hidden` 的静态画面，清除重复 ID，复制当前滚动位置。旧 Vue 实例立即释放引用，新视图不会误取旧列表。
- `wait-for-enter` 在异步目标实际进入前保留承接画面。快速切换只保留最新目标与必要的离场画面，不设动画点击锁。
- 普通布局节点在离场时固定几何；已有 fixed/absolute 根节点保持定位。`playing-page` 和 `settings-page` 根节点不加 transform，保证固定导航和歌词视口的坐标系不变。
- `v-if` 快速重开时，Vue 会替换离场节点。公共离场钩子将旧 WAAPI 效果的位置与速度交给新节点；音量抽屉保留原有横向居中变换，不从透明或位移起点重新播放。
- `drawer-right` / `drawer-left` 表示面板所属边缘，进入和退出都沿该边缘。`panel` 可指定内部移动节点；插件面板使用它保持整窗遮罩固定。
- 窗口隐藏、输入方式或动效偏好变化以及卸载时结束动画并清理画面。

调用者包括 `App.vue`、`SongList.vue`、`StreamingPage.vue`、`navigation/ApplicationPlaylistsPage.vue`、`PlayerBar.vue`、`player-bar/HiFiSidebar.vue` 和 `ExperienceFlyout.vue`。

### 导航方向：`app/useAppNavigation.ts`

`navigate()`、侧栏、前进和后退统一生成 `PageMotionName`。`App.vue` 注入按当前偏好排序、过滤和分组后的侧栏顺序；详情使用 `page-forward` / `page-back`。保留既有导航入口、历史、最近播放缓存和流媒体双页缓存规则。

### 连续对象：`app/motion/`

- `policy.ts`：每个窗口共享输入与偏好观察；新页面、指示器、封面和重排接入同一策略。
- `spring.ts`、`useNavigationIndicator.ts`：保存当前位置与速度；ResizeObserver 处理尺寸变化，分组变化单独重测。指示器测量按钮的布局尺寸，悬停平移、按压缩放和按压 CSS 变量不会使背景跳变或停在缩小的位置。
- `trajectory.ts`：将弹簧一次采样为 WAAPI 关键帧，由浏览器播放；重定向时采样当前进度并继承速度。尾部修正让终点位置与速度精确归位，不用逐帧在 JavaScript 中推动页面。
- `useSharedArtwork.ts`：独立的不可交互封面绘制层。快速反向复用同一张已绘制图片，从当前矩形与速度继续；结束、换歌、封面来源变化、窗口缩放和偏好变化时恢复真实封面。
- `reorderMotion.ts`：只处理已挂载条目；邻项从当前轨迹接向新位置，无需每次换目标都读取每个邻项的 computed style；业务顺序在放手时变更，之后以 FLIP 落位。
- `composables/useHoldReorder.ts`：保留长按、鼠标移动阈值、触摸滚动、自动滚动、Escape 取消和防误点击规则，接入上述绘制层。

导航选中背景继续使用主题的表面与圆角；各预设保留自身的渐变、状态灯或极简圆点，而不是叠加一块通用高亮。

### 时序与偏好

`assets/base.css` 新增页面进入、页面退出、抽屉退出、共享封面以及小浮层/折叠退出 token；原有公开主题 token 的含义不变。

保留 `system / full / reduced / off`。新页面过渡在 reduced 下使用 100ms 淡化，不产生位移；指示器和共享封面直接到位；off 与键盘触发的新页面路径立即完成。原生弹窗、旧式遮罩与小浮层同样使用 reduced 100ms 淡化，保留焦点恢复和原生顶层生命周期。

歌词物理模型、音频播放时钟、进度条与 Core 播放状态没有合并到通用页面动画中。

## 保留的侧栏几何约束

主内容随侧栏开合的 `padding-left` 过渡仍保留。它维持右侧边缘与文字比例，不能直接换成整页 translate 或 scaleX。

本次验证覆盖布局、交互和滚动距离的刷新率一致性；尚未采集真实曲库负载下的 60Hz / 120Hz 帧追踪。后续如要优化侧栏布局动画，应先测量实际布局耗时，再决定是否对可见卡片采用一次布局后的逐项位移；右边缘和文字比例仍是验收条件。
