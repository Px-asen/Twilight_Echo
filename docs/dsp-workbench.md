# DSP 工作台

点击标题栏中“声区”左侧的**DSP 工作台**调节图标，即可打开工作台；总 DSP 关闭时也可打开，不会自动开启处理。再次点击可返回，未保存的修改仍需先处理。

也可按 **Ctrl+K** 搜索“DSP 工作台”，或从播放器的均衡器按钮进入工作台的均衡器页。

## 实时 EQ 与场景草稿分别生效

- **均衡器**编辑当前活动场景，调节结束后实时提交。手动频段与 OPRA 耳机补偿分开保存、叠加一次。总 DSP 或 Direct 旁路时，进入页面不会开启处理。检测到活动场景改变时，阻止旧编辑继续提交并重新读取配置。
- **效果链**只编辑草稿。“保存更改”保存全部场景，并重新应用当前活动场景；选择或编辑另一个场景不会固定播放它。
- **固定使用此场景**与**恢复自动匹配**单独控制场景选择。规则属于场景：设备、后端、布局、源格式及采样率范围共同匹配，离线设备 ID 仍可见。
- 效果链支持撤销、重做、还原。切换至实时 EQ、离开、重新载入、导入或导出配置包前，未保存的草稿需选择保存、放弃或取消。保存失败保留草稿。

“已保存”表示提交完成；底栏“已生效”还要求请求、已确认与原生 revision 一致。DSD Direct / DoP 转 PCM 需另行确认，取消继续直通。Direct 保持原有旁路行为。

## 在链路中调节，在资料页管理

效果链支持现有 17 类节点的串行处理、旁路、删除和排序。拖动或使用上移／下移按钮；节点选择按钮聚焦时可用 Alt+↑ / ↓。原生 ABI v1 固定在末端，单例节点不能重复添加。

EQ 节点复用频响图和频段编辑器，但只写选中场景草稿。图形模式保持十段峰值滤波；参数模式支持最多 32 段。

“资料与插件”管理 IR、校正文件、VST3 状态与预设。先在效果链选择相应节点，再绑定资料。已保存场景或当前草稿仍引用的资料不可删除；解除引用并保存后才可删除。VST3 总开关、扫描目录、扫描结果和隔离重扫集中在此页，参数仍在节点编辑器中调节。

导入配置包会**替换全部场景与固定选择，并立即应用**，执行前需确认。导出前先解决草稿保存状态。

## 独立窗口移动同一个编辑器

点击“弹出窗口”将现有组件移动到独立窗口；不创建另一套播放器、Pinia 或草稿控制器。点击“收回”，或关闭独立窗口，编辑器回到主窗口并保留草稿。主窗口关闭前仍保护未保存的场景草稿。

工作台跟随应用主题、字体、背景与控件材质。效果链内容宽度至少 1120px 时使用三栏；800–1119px 使用场景选择器；不足 800px 切换查看链路与参数。

## 监测与等响度试听

底栏只显示引擎状态、实际采样率、响度、真峰值、节点处理耗时和 ACK。完整测量、延迟、尾音、节点状态与原始诊断位于“监测”。处理耗时的单位是 ms，不换算为 CPU 占用率。

诊断共享一个不重叠的轮询器：可见且播放时至多 4Hz，暂停时降低频率，隐藏时停止。EQ 频谱沿用播放器的共享消费者；资料列表不随电平刷新。

效果链底部的等响度 A/B 使用现有测量与补偿能力。先记录 A，修改草稿形成 B，再测量、选择试听，退出后恢复原配置。支持本地单／双声道 PCM、原采样率、正常速度、无处理或单个内置 EQ；不支持的音源、链路或输出条件在测量前显示。实时 EQ 的 A/B 快照切换仍是配置切换，不能代替等响度测量。

## 检查入口

```powershell
pnpm run test:dsp-workbench
pnpm run test:dsp-workbench:ui
pnpm run typecheck
pnpm run build
```

工作台单元测试执行实际控制器和工具函数；UI 测试渲染真实组件，但使用 API 测试桩。最终验收还需生产构建、真实应用截图、窗口生命周期与真实音频引擎交互。当前证据及环境阻塞见 `tmp/dsp-workbench-qa/STATUS.md`。
