# Twilight Echo 2.0.0

2.0 将曲库、播放和设备控制集中到 Twilight Core，并加入独立 Server、多音区同步播放与同步组 AutoMix。你可以在桌面管理音乐，让另一台连接 DAC 的设备负责输出，也可以把 Core 独立运行在服务器上。

对比范围：**1.3.1 正式版 → 2.0.0**，包含期间 1.4 系列的功能与修复。

## 独立 Core、Server 与远程管理

- 曲库、播放队列、搜索、歌词、插件、DSP 和设置统一由 Core 管理；关闭或恢复界面时，播放会话与业务状态持续保留。
- 新增不依赖 Electron 窗口的 Node Server，支持 Windows 自包含服务包与 Linux x86_64 容器部署。
- 提供命令行初始化、健康检查、备份恢复、候选版本升级与回滚，以及 Windows 服务宿主。
- 手机与其他客户端可通过 TLS 配对管理曲库、歌单、标签、Focus、队列、播放与 DSP；媒体访问保留设备授权和证书指纹校验。
- 桌面配置迁移可同时带入多个音区、同步组、独立队列、播放位置、组 AutoMix 设置及成员 DSP 资产。
- 提供面向 Android 与嵌入式宿主的可移植 Core、音源接口及 Provider 插件运行时，方便集成共享播放能力。

## 多音区、Audio Bridge 与同步组 AutoMix

- 新增音区工作区：每个音区拥有独立队列、进度、DSP 和输出目标，可查看设备、分组关系与信号链。
- Audio Bridge 在 Core 与远端输出设备之间传输 TLS 音频流，扩展多声道 PCM、DoP 和原生 DSD 格式协商。
- 同步组使用共同的播放、暂停、跳转与切曲决策，并根据时钟反馈调整 PCM 播放速率。
- 支持同步组自然过渡与 DJ AutoMix：全组共享过渡决策，各成员使用自己的采样率、准备任务与 DSP 延迟补偿。
- 改善连续切曲、重复曲目身份、卷积尾音与源时间线处理；取消、断线或成员失败时撤销待执行操作，恢复后保持暂停。
- Bridge 连接失败时保留远端输出选择，避免意外切回本机扬声器。

## 曲库、资料与搜索

- 本地音乐集合和队列迁移至持久化 SQLite 服务，完善大曲库分页、窗口化浏览及外部歌单导入。
- 新增艺术家详情与资料管理，支持多艺术家署名、公共资料识别、专辑与录音匹配，以及人工复核和修改。
- 扩展流派、标签、个人评分、Focus 筛选、版本关系、音乐探索和曲库健康诊断。
- 搜索增加相关性排序与拼写纠错；本地列表、最近播放、流媒体和网络音乐源统一提供当前曲目定位。
- 修复播放历史、最近播放和队列中的封面丢失问题；播放快照未改变时保留已加载的分页结果。
- 批量统计不再扩张显示缓存，过期的元数据失败记录会释放；代理、网易云与服务发现实现按需加载。

## 音频引擎与 DSP

- 重构 DSP 工作台、信号检测、路由、场景和参数均衡器控件，补充内置与自定义预设管理。
- 集成 OPRA 耳机频响补偿目录，完善重采样、响度分析、True Peak、交叉馈送与输出策略。
- 新增 32 位 ASIO 驱动辅助进程，让 64 位桌面程序能够使用仅提供 32 位驱动的设备。
- 改善 WASAPI 独占设备切换、实际设备身份反馈、占用错误分类及 PCM/DoP 识别。
- 完善 CUE 切片投射、流式寻道、队列切换与音频服务关闭流程。
- 音频服务启动失败时仍可进入曲库和设置；连续失败后停止自动重试，可在故障面板手动恢复，恢复后由用户继续播放。

## 外观与交互

- 新增分层材质、2D/3D 外观预览与主题编辑工作区，支持主题快照及主题插件导入导出。
- 播放页加入随封面色彩与音频变化的流体背景。
- 统一页面、弹窗、抽屉、导航指示器和封面的过渡；快速反向操作能从当前画面接续，拖拽排序保留跟手反馈。
- 动效遵循系统或应用的减少动态效果设置，并保留弹窗焦点和键盘操作。
- 改进本机 OpenType 字体家族识别，解除原字体列表上限，并支持手动输入字体名称。
- 修复桌面歌词显隐、关联字体同步、全屏状态和余晖模式恢复；完善深浅色任务栏图标与设置搜索定位。

## 插件、安全与稳定性

- 扩展侧栏小组件、标题栏浮层、完整界面插件与设置按钮，并提供 SDK 示例和集成文档。
- 增加官方浏览器登录入口和网易云播放报告，完善登录取消、宿主启停及异步请求生命周期。
- 加强异常关机后的配置与数据库恢复，修复 Linux 音乐目录递归监听和 MPRIS 媒体控制同步。
- 更新 Electron 与生产网络依赖；升级 `follow-redirects`、`qs`、`node-forge`，保留必要的归档安全补丁与自动审计。

## 升级说明

- 从 1.3.1 升级前，建议备份个人数据；首次启动会迁移曲库与设置，请等待迁移完成。回退旧版时使用升级前的备份。
- 使用 Bridge 或同步组时，Core 与成员设备应一起升级，新的音频格式和组 AutoMix 需要双方支持。
- 本次没有发布新的 Android 或 iOS 安装包；相关运行时和后端供集成使用。
- ASIO、实验性 PCM→DSD，以及 macOS/Linux 音频设备仍需按具体驱动和设备验证。容器与模拟 DAC 测试不代表物理设备的同步精度测量。
