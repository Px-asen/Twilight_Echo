# Twilight Echo v1.4.0

_统一内核，跨端声场，纯净直达。_

`v1.4.0` 是自 `v1.3.1` 以来的重大架构与音频体验升级版本。本次更新完成了**统一共享内核（Twilight Core）与多端可移植运行时**的全面切换，新增**局域网 TLS PCM 音频输出桥（Audio Bridge）**与**多 Zone 独立播放会话**，重构了 **DSP 音频工作台、OPRA 耳机频响补偿与 32 位 ASIO 驱动桥接**，将本地曲库全面升级为**持久化 SQLite 曲库与公共资料智能识别系统**，并带来了**流体音频响应背景、2D/3D 外观工作区与 OpenType 原生字体解析引擎**。此前 `1.4.0-preview` 系列中的所有特性与修复均已包含在本正式版中。

> [!NOTE]
> **对比范围：`v1.3.1` → `v1.4.0` 正式版。**

---

## 本次更新重点

- **统一共享内核（Twilight Core）与跨端运行时**：全量业务逻辑收敛至独立共享内核，支持桌面独立子进程、局域网 Core 网关以及 Android / 嵌入式 `music-core.js` 可移植宿主。
- **局域网 TLS PCM 输出桥（Audio Bridge）与多 Zone 会话**：支持将一台电脑作为 Core（负责解码与 DSP），通过加密 TLS 流将处理后的 PCM 实时推送至局域网另一台接有 DAC 的电脑输出；支持同一 Core 下的多 Zone 独立队列、DSP 与隔离音频进程。
- **原生音频引擎与专业输出升级**：集成 `soxr` 高精度重采样、`ebur128` 响度分析、`bs2b` 交叉馈送与 `libusb` USB 直通调度；新增 **32 位（x86）ASIO 驱动独立桥接进程**、**DSD512 调制**、**OPRA 耳机补偿曲线**及 **CUE 切片无损投射**。
- **持久化 SQLite 音乐库与智能资料识别**：曲库、流派、标签、Focus 筛选、评分与探索视图全面迁移至 SQLite（Schema 30），支持十万级曲库窗口化浏览、艺术家详情页、多源资料交叉核验与曲库健康诊断。
- **2D/3D 外观工作区、流体背景与字体引擎**：新增 Apple Music 风格音频响应流体背景（Fluid Backdrop）、分层材质与完整外观快照、原生 OpenType 字体解析（解决日文/OTF 字体家族乱码与截断）及深浅色任务栏缩略图控制图标。
- **极端故障自愈与启动优化**：新增 Windows 蓝屏（BSOD）/断电导致的 0 字节配置与 SQLite WAL 损坏自愈能力，大幅优化并发启动与退出耗时。

## 新增与扩展功能

### 1. 统一共享内核（Twilight Core）与多设备互联

- **全量业务收敛至共享内核**：将曲库、播放会话、Occurrence 队列、搜索、歌单、书签、歌词、均衡器/DSP、远程投射、统计与设置统一收敛至 `src/core/`，主进程、渲染器与原生音频服务通过强类型命令协议与因果状态投影通信。
- **可移植嵌入式运行时（`music-core.js`）**：新增 ES2017 / QuickJS 兼容的独立内核包与宿主桥接层（`portableEmbeddedHost`），支持流式音源读取（Seekable Host Inputs）、SAF 曲目身份映射、可移植 AutoMix 协调器及 LRCLIB 歌词回退搜索。
- **局域网遥控网关与安全配对**：扩展 `/api/core/rpc` 与 `/api/core/events` 接口，支持证书指纹固定的 TLS 配对（Pinned TLS Pairing）、ALAC/多格式媒体流传输以及远程歌词与信号链查询。
- **Cast CUE 独立切片投射**：DLNA / Cast 投射整轨 CUE 分轨曲目时，通过原生 `PcmSegmentRenderer` 按曲目范围渲染独立 WAV 切片，保留相对进度游标与切曲状态，不再整盘重头播放。

### 2. 局域网音频输出桥（Audio Bridge）与多 Zone 会话

- **TLS PCM 音频输出桥（第一阶段）**：
  - 支持在两台运行 Twilight Echo 的电脑之间建立固定证书指纹与一次性令牌鉴权的 TLS 32-bit Float PCM 音频桥（44.1–192 kHz）。
  - 主控端（Core）完成解码、参数均衡、DSP 与重采样后推送至接收端（Bridge），接收端跳过重复 DSP 直接驱动指定的 WASAPI 独占 / ASIO / 硬件 DAC，并实时回报硬件采样率、位深、缓冲水位、驱动消耗帧数与欠载计数。
  - 严格的静音与隔离安全围栏：Pause / Seek / Stop / 切曲同步清空远端环形缓冲；断网、设备失效或配置文件损坏时自动隔离并停止播放，**绝不静默回退到本地扬声器外放**。
- **多 Zone 独立会话（第二阶段基础）**：
  - 新增 `CoreZoneRegistry` 与隔离的 `zone-audio` 服务进程，支持在同一 Core 下创建多个独立 Zone，各自拥有独立的 SQL 播放队列、播放进度、DSP 配置与输出目标。

### 3. 原生音频引擎、DSP 工作台与 ASIO / USB 进化

- **32 位 ASIO 驱动桥接（x86 Helper）**：新增独立编译的 32 位 `twilight-asio-helper-x86.exe` 辅助进程与跨进程共享内存/IPC 协议，使 64 位主程序能够无缝枚举、加载并低延迟驱动仅提供 32 位 COM DLL 的经典声卡 ASIO 驱动（#208, #209）。
- **第三方专业音频算法与 USB 直通架构**：
  - 集成 `libsoxr` 高精度重采样、基于 `libebur128` 的多声道响度与 True Peak（真峰值）分析、`libbs2b` 耳机交叉馈送（Crossfeed）以及 `libusb` 异步/隐式反馈 USB 音频包调度器。
  - 新增 Android AAudio / Oboe / JNI 输出后端、Android USB PCM 采样率策略钩子与 iOS AudioUnit 输出后端。
  - 扩展重采样相位配置、目标采样率策略（最高支持 768 kHz PCM）与 **DSD512** 调制器；原生支持 SACD ISO 与 WavPack 流式寻道解码。
- **DSP 工作台与均衡器重构**：
  - 重构音频工作台界面（信号检测、路由、输出设置、场景监测与参数均衡器控件），播放进度条支持 2000 点高精度分析波形展示。
  - 集成 **OPRA 耳机频响补偿目录**，支持一键查询并提交耳机补偿参数至 Core DSP，内置与自定义均衡器预设管理全面升级。

### 4. 持久化 SQLite 音乐库、智能资料识别与搜索

- **持久化 SQLite 音乐库（Schema 30）**：
  - 本地曲库集合、流派、标签、Focus 筛选、个人评分与探索视图全面迁移至 SQLite 独立服务，支持十万级大曲库窗口化流畅浏览、外部歌单导入与队列编辑。
  - 新增空闲期内存索引自动释放机制（`SymSpellIndex` 与专辑别名缓存空闲 90 秒后自动回收）并收敛 SQLite 页缓存上限，显著降低后台常驻内存。
- **艺术家详情页与多源公共资料智能识别**：
  - 新增艺术家详情页、多艺术家署名拆分（支持 `&` 与多值标签）及资料管理工作台。
  - 支持公共资料源、艺术家与录音交叉核验、专辑子集识别及 NCM 文件身份解析；支持手动切换艺术家档案并保留编辑状态。
- **曲库健康诊断与统一纠错搜索**：
  - 新增曲库健康诊断、重复曲目检测与收件箱处理流程；完善设置与个人音乐资料备份恢复。
  - 搜索引入相关性排序与 SymSpell 拼写纠错；桌面端所有歌曲列表、主页、最近播放、流媒体歌单及网络音乐源统一支持「定位当前播放曲目」按钮。

### 5. 2D/3D 外观工作区、流体背景、字体引擎与插件扩展

- **流体音频响应背景（Fluid Backdrop）**：播放页新增基于封面色彩母带处理（Cover Mastering）与实时频谱能量驱动的 Apple Music 风格流体背景渲染器。
- **2D/3D 外观工作区与主题工坊重构**：
  - 新增分层材质（液态玻璃 / Bohr 材质 / 卡片图层）与 2D/3D 窗口实时预览编辑工作区。
  - 主题工坊内聚为原生高级定制面板（`CustomThemeAdvancedPanel`），支持完整外观快照导出与导入。
- **原生 OpenType 字体解析引擎**：
  - 直接解析本地 `.ttf/.otf/.ttc/.otc` 字体文件的 OpenType `name` 表（优先提取 DirectWrite / Chromium 匹配的 Typographic Family Name ID 16/21 及多语言本地化名称），彻底解决森泽（Morisawa `FOT-`）等日文字体在 Windows 注册表中的 Shift-JIS/GBK 乱码及字重拆分导致 CSS 不生效的问题（#199, #204）。
  - 解除原本地字体枚举上限（600 项）与下拉列表渲染上限（200 项），并支持手动输入本机字体名称。
- **插件侧栏小组件与标题栏浮层**：插件系统新增侧栏小组件体验（Sidebar Widget Experiences）、标题栏体验浮层（Titlebar Flyouts）、插件设置表单按钮字段（`button`）及 Android 串行 Provider 插件运行时。
- **深浅色自适应任务栏图标**：Windows 任务栏缩略图工具栏（SMTC / Thumbar）新增深色与浅色主题自适应图标（上一首、播放/暂停、下一首、喜欢）。

## 改进、修复与稳定性

- **蓝屏（BSOD）/ 断电崩溃自愈与启动提速（#210）**：
  - 自动检测并隔离修复因 Windows 蓝屏或断电留下的 0 字节/截断 JSON 持久化文件（`library-identity.json`、`remote-devices.json`、`remote-tls.json`、`bridge-output-selection.json` 及 `VersionedDataStore` 文件），备份为 `.corrupt` 并安全重建。
  - SQLite 曲库与 `core-state.sqlite` 在检测到未检查点的 WAL 或损坏时自动尝试 `REINDEX` 或隔离重建；仅在存在未检查点 WAL 或跨版本迁移时执行启动 `PRAGMA quick_check`，大幅缩短大曲库冷启动时间。
  - 并行化 Core 独立服务初始化与关闭，并发预加载渲染器图标字体与启动快照，新增可拖拽的启动加载与故障恢复兜底界面。
- **WASAPI 独占与 ASIO 稳定性修复**：
  - 修复 WASAPI 独占模式下播放中切换设备档案报错 `output_target_not_ready` 的问题，补齐 WASAPI Exclusive、CoreAudio 与 ALSA 的 `actualDeviceId` 上报（#198, #203）。
  - 修复旧音频服务退出前未静音导致 USB DAC 驱动残留占用、以及将 `AUDCLNT_E_DEVICE_IN_USE` 误判为格式不支持的问题，新增占用进程检测与恢复面板（#185, #195）。
  - 为 ASIO 自动缓冲引入采样率感知的下限保护（Rate-aware Auto Buffer Floor）与欠载率告警（#180, #184）；修正 WASAPI 独占下 PCM 与 DoP 的区分逻辑（#170, #171）。
- **播放、封面与歌词细节修复**：
  - 修复播放历史与最近播放歌单在切曲或流媒体播放后封面丢失的问题，支持持久化封面投影与缺失封面自动回填（#205）。
  - 修复修改普通歌词字体时关联样式层（当前/附属/翻译/罗马音）未同步更新的问题，新增「同步到全部」操作（#186, #194）。
  - 修复透明紧凑模式下可视化频谱对比度不足的问题。
  - 修复 Linux MPRIS 桌面媒体控制状态同步（#188）及音乐文件夹递归监听问题（#187）。
- **运行时与依赖安全更新**：升级 Electron 至 `43.8.1`，同步升级 `undici`、`ip-address`、`body-parser` 等依赖的安全修复版本。

## 安装包

本次正式版同时发布 Windows、macOS 与 Linux 安装包，每个安装包均附带同名 `.sha256` 校验文件。

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10/11 x64 | `TwilightEcho-1.4.0-setup.exe` | 内置 64 位原生引擎与 32 位 ASIO 桥接器；未做商业代码签名，可能出现 SmartScreen 提示 |
| macOS（Apple 芯片） | `TwilightEcho-1.4.0-mac-arm64.dmg` / `.zip` | 未签名、未公证，首次打开需右键 →「打开」 |
| macOS（Intel） | `TwilightEcho-1.4.0-mac-x64.dmg` / `.zip` | 同上 |
| Linux x64 | `.AppImage` / `.deb` / `.rpm` / `.tar.gz` | AppImage 需先执行 `chmod +x` |

macOS 首次运行若被 Gatekeeper 拦截，可在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/TwilightEcho.app
```

## 升级说明

- `1.4.0` 为 **稳定频道** 正式版；已安装 `1.3.1` 或 `1.4.0-preview` 系列版本的用户可直接覆盖安装，首次启动会自动完成曲库与配置向统一 Core 存储的迁移。
- 使用局域网音频输出桥（Audio Bridge）时，主控端与接收端电脑均需升级至 `1.4.0` 并处于可互通的局域网内。
