# Twilight Echo 1.4.0-perview0 更新说明

本次版本是自 `1.3.1` 以来的大型架构与体验升级版本：完成了统一共享内核（Twilight Core）与多端可移植运行时演进，重构了 DSP 音频工作台与持久化 SQLite 音乐库，新增公共资料智能识别、2D/3D 外观工作区，并集中修复了 WASAPI 独占输出切换、ASIO 自动缓冲、本地日文/OTF 字体解析与歌词字体同步等多项关键问题。

---

## 1. 架构升级：统一共享内核（Twilight Core）与多端运行时

- **统一共享内核收敛**：将曲库、播放会话、队列、搜索、歌单、书签、歌词、均衡器/DSP、远程投射、统计与设置收敛至统一的共享内核（`src/core/`），主进程、渲染器与独立音频服务通过强类型命令协议与因果状态投影通信（#181, #193, #201）。
- **独立可移植运行时（`music-core.js`）**：新增可独立打包的 ES2017 / QuickJS 兼容内核构建与宿主桥接层（`portableEmbeddedHost`），支持嵌入式自定义流式音源读取（Seekable Host Inputs）、音频设备桥接与歌词同步。
- **跨平台与移动端底层适配**：新增 Android AAudio / Oboe / JNI 输出后端、iOS AudioUnit 输出后端，以及 Android 串行 JavaScript Provider 插件运行时与插件仓库工具链。
- **局域网遥控与多设备互联**：局域网遥控网关扩展 `/api/core/rpc` 与 `/api/core/events` 接口，支持受信任设备发现、配对管理与媒体桥接。

---

## 2. 音频引擎、DSP 工作台与独占输出修复

- **DSP 工作台与参数均衡器重构**：
  - 重整音频工作台界面（信号检测、路由、输出设置、场景监测与参数均衡器控件），播放进度条支持 2000 点高精度分析波形展示。
  - 扩展重采样相位配置、目标采样率策略与 DSD512 调制支持；补充音频回调负载、削波统计、响度范围与静音边界实时遥测。
  - 修复 DSP 旁路（Bypass）状态保持问题，以及调整均衡器时 IPC 载荷无法结构化克隆的报错（#167, #177）。
- **WASAPI 独占模式与故障恢复**：
  - 修复 WASAPI 独占模式下播放中应用设备档案必定报 `output_target_not_ready` 并触发回滚的问题，为 WASAPI Exclusive、CoreAudio（共享/独占）与 ALSA 补齐 `outputInfo.actualDeviceId` 上报及路由回退匹配（#198, #203）。
  - 修复旧音频子进程退出前未静音导致部分 USB DAC 驱动残留占用、以及将 `AUDCLNT_E_DEVICE_IN_USE` 误判为采样率/位深格式不支持的问题；新增占用进程检测与 Core 音频故障恢复面板（#185, #195）。
  - 修正 WASAPI 独占模式下 PCM 与 DoP 输出的区分判定逻辑（#170, #171）。
- **ASIO 与 Linux 平台修复**：
  - 为 ASIO 自动缓冲引入采样率感知的下限保护（Rate-aware Auto Buffer Floor），并在欠载率偏高时给出明确告警（#180, #184）。
  - 修复 Linux MPRIS 桌面媒体控制状态同步问题（#188）及音乐文件夹递归监听问题（#187）。

---

## 3. 音乐库、智能资料识别、曲库健康与搜索

- **持久化 SQLite 曲库与大曲库窗口化**：
  - 本地曲库集合、流派、标签、Focus 筛选、评分与探索视图全面迁移至持久化 SQLite 服务（Schema 29，含旧音频文件发行日期增量回填与任务取消/恢复保护）。
  - 支持十万级大曲库窗口化流畅浏览、外部歌单导入与队列编辑。
- **音乐资料与公共音源智能识别**：
  - 新增艺术家详情页与集成资料管理；支持公共资料源、艺术家与录音交叉核验、专辑子集识别及 NCM 文件身份解析。
  - 优化后台刷新期间的艺术家编辑态保持与公共缓存稳定性。
- **曲库健康诊断与个人备份**：新增曲库健康诊断与重复曲目/收件箱处理流程；完善首次导入引导及设置/个人资料备份恢复。
- **统一搜索与当前曲目定位**：引入搜索相关性排序与拼写纠错；桌面端各歌曲列表、主页、最近播放、流媒体歌单及网络音乐源统一支持「定位当前播放曲目」按钮（#139, #160）。

---

## 4. 外观工作区、本地字体引擎与歌词个性化

- **新版 2D/3D 外观工作区**：新增分层材质（液态玻璃 / 卡片材质）与 2D/3D 窗口预览编辑工作区；统一紧凑型控件视觉与焦点状态（#189）；优化本地主页与播放页背景图层过渡。
- **本地字体解析重构与界面字体自定义**：
  - 直接解析本地 `.ttf/.otf/.ttc/.otc` 字体文件的 OpenType `name` 表（优先提取 DirectWrite / Chromium 匹配的 Typographic Family Name ID 16/21 及多语言本地化名称），彻底修复森泽（Morisawa `FOT-`）等日文字体在注册表中的 Shift-JIS/GBK 乱码及按字重拆分名称在 CSS 中不生效的问题（#199, #204）。
  - 解除原本地字体枚举上限（600 项）与下拉列表渲染上限（200 项），完整呈现系统与用户字库。
  - 「设置 → 外观 → 界面字体」新增手动输入本机字体名称支持（#199, #204）。
- **歌词字体同步与排版优化**：优化歌词字号布局；修复修改普通歌词字体时关联样式层（当前/附属/翻译/罗马音）未同步更新的问题，并提供「同步到全部」操作（#186, #194）。

---

## 5. 插件系统、余晖模式与安全更新

- **插件能力扩展**：插件设置表单新增按钮字段（`button`）支持（#168）；对齐插件分发信任、下载与 Provider 契约。
- **余晖模式（Afterglow）与播放持久化**：强化曲库队列持久化、余晖模式接管/恢复与退出时的播放进度保存。
- **运行时与依赖安全更新**：升级 Electron 至 `43.8.1`，同步更新 `undici`、`ip-address`、`body-parser` 等依赖以修复安全公告；完善 GitHub Releases 跨平台安装包发布流水线。
