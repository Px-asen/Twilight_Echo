# Twilight Echo 2.0.1

2.0.1 改善长时间浏览和播放时的内存生命周期，修复收藏播放、搜索闪动、歌词宽度及 DSD/ASIO 输出问题，并加入可重试的调试会话与 Windows 崩溃取证，方便反馈难以复现的音频故障。

对比范围：**2.0.0 → 2.0.1**。

## 播放、搜索与界面修复

- 修复网易云收藏列表加载较慢时，较早的点击在稍后覆盖新播放曲目的问题。点击播放立即提交给 Core，列表继续加载不会再次切歌；随机播放使用完整收藏队列。（#213）
- 修复后台补全音乐资料时，实体搜索结果反复刷新、闪动的问题。（#222）
- 修复宽屏歌词页没有遵循最大宽度设置的问题。（#200）
- 修复 150% 等非整数显示缩放下，侧栏选中背景与条目边界不对齐的问题。（#224）
- 完善独占模式暂停自动释放设置的应用、持久化、失败回退及重新打开设置页后的显示。
- 修复部分旧版备份中的歌单缺少创建时间时无法恢复的问题，保留歌单成员并使用备份记录中的时间补齐。

## DSD 与 ASIO 输出

- 保留用户选择的 DSD 输出路由，并使播放状态与实际输出信息一致。（#218）
- 修复 Native DSD 切换时 ASIO 缓冲单位变化导致设置失效的问题。对报告一致比例的驱动进行单位换算，保留用户的 PCM 缓冲偏好，并在诊断中记录实际驱动计数。（#212）
- 完善原生队列在暂停边界的处理，保留当前曲目、进度和音量，阻止到达边界后自动启动下一首。

## 内存与后台服务

- 卷积器仅保留当前采样率所需的运行数据，关闭或卸载时释放不用的缓冲；AutoMix 清理过期的预备任务与目标状态。
- 曲库空闲后释放临时索引、查询缓存和闲置 SQLite 页面；远程封面写入缓存后释放不再需要的内容。
- 备份、导入、重复检测、曲库体检、云传输和插件市场按需启动，已有的待恢复备份与待处理导入仍按原流程恢复。
- 模型安装使用独立后台进程，完成或取消后退出；播放器面板和相关数据订阅按需创建。

## 浏览与工作台恢复

- 流媒体详情页改用 Core 管理的磁盘分页缓存，界面只保留当前显示窗口。完整播放、随机播放、全选、收藏和加入歌单仍覆盖完整列表。
- 返回已浏览页面时恢复筛选、排序、滚动位置、详情历史和草稿；账号或来源上下文变化后清理失效会话。
- 修复聚合歌单切换隐藏音源后，来源筛选状态和计数没有及时刷新的问题。
- Bilibili 分 P 列表的折叠与组内翻页保持独立，折叠显示不会缩短完整播放队列。
- 外观、主题和音频工作台卸载闲置组件后，可恢复编辑草稿、撤销历史、编辑位置和预览视角，继续保留离开确认流程。

## 调试会话与崩溃取证

在 **设置 → 系统与关于 → 日志与问题排查** 中点击 **开始调试**，复现问题后选择 **结束并导出调试包**。取消保存会继续记录，导出失败后可以重试。

- 调试包关联界面操作、Core、音频服务和原生模块启动过程；进程退出后仍保留最近状态、故障时间和可用证据。
- Windows 可勾选 **启用崩溃取证**，重启后采集原生进程崩溃。界面显示采集状态、失败阶段和转储数量，结束取证后重启并完成导出。
- 每个调试会话最多保留 3 份完成的转储，支持 32 位与 64 位原生采集器；发布符号归档帮助开发者定位代码行。
- 调试日志包含完整本地路径；文本认证信息会过滤，崩溃转储可能包含敏感内存片段。记录保存在本机，导出时可选择是否附带转储。

音频启动崩溃的具体根因仍需结合故障机器的模块记录和堆栈定位。使用步骤见 [调试与诊断指南](../diagnostics.md)。

## 便携 Core 定时暂停

面向 Android 和嵌入式宿主，新增按经过时长或本地时间安排的定时暂停，并支持“播完当前曲目”。计时与设备启动周期关联，可在同次设备启动中的宿主重建后恢复；设备重启后丢弃旧任务。触发时保留队列、播放位置和用户音量，便携宿主会明确拒绝尚未实现的桌面定时模式。

## Windows 可选 Node 桌面宿主

Windows x64 增加独立 Node 后台运行路径，安装包包含固定版本运行时，无需用户另行安装 Node。使用 `TwilightEcho.exe --core-host=node` 显式启用；恢复默认方式启动，或传入 `--core-host=electron`，即可使用 Electron 宿主。

默认桌面宿主继续使用 Electron。独立 Node 路径仍处于试用阶段，生产环境整机内存对照及长时间播放验收尚未完成。运行方式和验证范围见 [内存架构说明](../memory-architecture-2026-11-08.md)。
